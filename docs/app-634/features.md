# 634 - возможности (продуктовый канон)

Источник формулировок: продуктовый копирайт сайта (`/masters#app`, i18n `app.feat.*`). При расхождении с UI приложения приоритет у фактического экрана в TestFlight/App Store - зафиксируйте расхождение Issue-ом.

## Проекты
Эскиз конкретной татуировки клиента живёт в **проекте**, не в галерее телефона. На следующем сеансе по этой же работе мастер открывает проект в 634, а не ищет файл в Telegram / WhatsApp / Photos.

## Пипетка
Цвет берётся с эскиза в проекте (с лупой), не «на глаз» - старт подбора пигмента для колора или попадания в уже набитый участок.

## Подбор %
Сверка цвета референса с флаконами, которые реально есть на складе. Удобно на продолжении рукава / цветной работы через месяцы.

## Метки на эскизе
Зоны: что сделано, какой пигмент, что править на следующем сеансе той же татуировки. Заметки в 634, не в переписке с клиентом.

## Доминантные цвета
Список основных цветов референса перед сеансом - быстрее собрать флаконы.

## Склад
Остатки краски видны до загруженной недели; меньше сюрприза в день сеанса.

## Бренды
Линейки и флаконы привязаны к складу и к проекту по татуировке - конкретный пигмент, не «какая-то красная».

## Шеринг
Клиент получает утверждённый эскиз из проекта - один файл у обеих сторон перед сеансом.

## Клиенты / календарь (на скриншотах сайта)
На лендинге есть экраны клиентов и календаря как часть галереи приложения. **Не описывать** их как полноценную CRM-запись без подтверждения из билда. При задачах на эти экраны - сверять с актуальным UI 634.

## Скриншоты на сайте
Пути: `/img/app/real/*.png` (home, pipette, match, labels, dominant, share, brands, inventory, clients, calendar).
