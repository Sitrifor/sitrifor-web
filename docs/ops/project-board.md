# GitHub Project (канбан)

Создайте вручную (UI GitHub):

1. Org `Sitrifor` → Projects → New project → Board
2. Имя: `Sitrifor Delivery`
3. Колонки по `docs/kb/pipeline.md` (Inbox → … → Ready for You)
4. Привяжите репо `sitrifor-web`
5. Labels в репо: `product:web`, `product:634`, `type:feature`, `type:bug`, `type:techdebt`, `type:content`, `type:seo`

Карточки = Issues. Оркестратор агентов подключим после стабилизации доски.
