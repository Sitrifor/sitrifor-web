# Метрики приоритезации

BizDev + Strategist + Product считают score задачи:

| Метрика | Вес | Вопрос |
|---------|-----|--------|
| Выручка | 30 | Увеличивает оплату / конверсию в деньги? |
| Аудитория | 20 | Рост охвата / удержания мастеров и клиентов? |
| Ценность | 20 | Польза в работе мастера / студии? |
| Стабильность | 15 | Снижает сбои, техдолг, риск отказа? |
| Безопасность | 15 | Данные, доступы, юр. риски, ИБ? |

Impact по каждой: 0–5.  
`score = Σ(impact × weight)`.

Задачи с label `type:techdebt` проходят тот же скоринг - не в обход очереди.
